## Here-documents

Use a here-document when you want to feed a multi-line block into a command or write it into a file.
This is especially useful for generating small scripts, config files, SQL snippets, or test fixtures from shell scripts.

### Literal mode: quoted delimiter

Quote the delimiter when the content should be written exactly as typed.
Variables, command substitutions, and other shell expansions stay untouched.

```bash
cat > python_file_with_code.py <<'PY'
def greet(name):
    print(f"Hello, {name}!")

for i in range(3):
    print(i)

# Have a nice day! 🙂
PY
```

### Expansion mode: unquoted delimiter

Leave the delimiter unquoted when you intentionally want the shell to expand variables and command substitutions before writing the content.

```bash
NAME=Marcus

cat > python_file_with_code.py <<PY
Hello $NAME
Today is $(date +%A)
PY
```

### Rule of thumb

- Use `<<'EOF'` or `<<'PY'` for templates, scripts, YAML, Python, SQL, and anything that should remain literal.
- Use `<<EOF` or `<<PY` only when you deliberately want shell expansion.
- Pick a delimiter that describes the content, for example `PY`, `SQL`, `YAML`, or `SYSTEMD`.
